# Netflix Popularity Analysis

## Overview

Statistical analysis of Netflix content popularity using IMDb vote counts. The project investigates whether show type (Movie vs. TV Series) and genre influence audience engagement.

## Technologies

* Python
* Pandas
* NumPy
* SciPy
* Matplotlib
* Jupyter Notebook

## Key Tasks

* Cleaned and prepared Netflix dataset for analysis
* Performed exploratory data analysis (EDA)
* Conducted Independent Two-Sample t-Test to compare Movies and TV Series
* Conducted One-Way ANOVA to evaluate popularity differences among genres
* Visualized popularity trends using charts and statistical summaries

## Results

* Movies received significantly higher IMDb vote counts than TV Series
* Popularity varied significantly across genres
* Action content showed the highest average popularity
* Sports content showed the lowest average popularity
